# CareSync

[![Live Demo](https://img.shields.io/badge/demo-caresyncampayon.vercel.app-black)](https://caresyncampayon.vercel.app)

## Summary

CareSync is a web application built with Vite and JavaScript (`96.7%` JavaScript, `2.5%` CSS, `0.8%` HTML). CareSync streamlines health center operations by pairing digital patient registration and queue reduction with an RA 10173-compliant health record database and a real-time staff dashboard tracking appointments and physician availability.


- Live Deployment: [caresyncampayon.vercel.app](https://caresyncampayon.vercel.app)
- Repository: [winterygracie/caresync-draft](https://github.com/winterygracie/caresync-draft)

## Setup



### Prerequisites

- Node.js (v18 or higher recommended) and npm

### Installation

1. Clone the repository:

```bash git clone https://github.com/winterygracie/caresync-draft.git```
```bash cd caresync-draft```


### 2. Install dependencies

```bash npm install```

### 3. Start the development server

```bash Launch the Vite dev server and open the local URL shown in the terminal (usually http://localhost:5173)```
```bash npm run dev```
